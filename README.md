# Bug Tracker – Bug Tracking & QA Management System

Bug Tracker is a web-based application designed to simplify software bug reporting, tracking and management. It helps testers report defects, developers manage fixes and administrators monitor bug status.

## Features

- User Authentication – Secure user login and authentication.
- Role-Based Access – Admin, Tester and Developer roles.
- Bug Reporting – Create and report software bugs.
- Bug Assignment – Assign reported bugs to developers.
- Status & Priority Tracking – Track bug progress and priority.
- Comments – Communicate about reported bugs.
- Search & Filtering – Find and filter bugs easily.
- Notifications – Keep users informed about bug activities.

## Technology Stack

- Frontend: React.js, JavaScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDBs
- API: REST APIs
- Authentication: JWT
- Version Control: Git & GitHub

## Project Structure

- BugTrack/frontend – React frontend application
- backend – Express.js backend, routes, models and middleware

## Installation & Setup

1. Clone the repository.
2. Install backend dependencies.
3. Configure environment variables.
4. Start the backend server.
5. Install frontend dependencies.
6. Start the frontend development server.

## Purpose

The main objective of Bug Tracker is to improve collaboration between QA testers, developers and administrators by providing a centralized platform for defect management.
